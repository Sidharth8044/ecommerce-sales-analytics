# E-Commerce Sales & Profitability Analysis Dashboard

## Project Overview

This project analyzes e-commerce sales, profitability, order status, regional performance, monthly trends, and payment methods using Microsoft Excel and Power BI.

## Tools Used

- Microsoft Excel
- Power Query
- Power BI
- DAX

## Project Objectives

- Analyze total sales and profit.
- Compare sales performance across regions.
- Identify the most profitable products.
- Examine monthly sales trends.
- Understand order status and payment method distribution.

## Dashboard KPIs

- **Total Sales:** ₹1,39,20,890
- **Total Profit:** ₹26,85,840
- **Total Orders:** 495
- **Profit Margin:** 19.29%

## Key Insights

1. **Regional Performance:** South generated the highest sales at ₹45.22 lakh.
2. **Product Profitability:** Laptops generated the highest profit at ₹9.55 lakh.
3. **Order Fulfilment:** 370 of 495 orders were delivered, representing 74.75%.
4. **Monthly Trends:** December recorded the highest sales at ₹19.28 lakh, while September recorded the lowest at ₹5.87 lakh.

## Dashboard Features

- KPI cards for sales, profit, order count, and profit margin.
- Regional sales and monthly sales trend charts.
- Product profitability analysis.
- Order status and payment method analysis.
- Interactive Region and Category slicers.

The dashboard provides an overview of e-commerce performance and helps identify high-performing regions, profitable products, and areas for further investigation.
